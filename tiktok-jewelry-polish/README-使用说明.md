# TikTok 首饰图片 Skill V2.0 · 使用说明

本 Skill 用于制作和打磨 TikTok Shop 首饰商品图片。核心原则：**只改善图片，不擅自改变实物首饰。**

## V2.0 更新内容
- 支持图片打磨与参考图生图两种模式。
- 增加活口 / Bypass 戒指结构锁定，明确开口、上下端头、交叉点和 over-under 穿插顺序。
- 增加宝石色泽、自然光泽和金属质感控制。
- 增加平面拍摄、微距细节、真人佩戴、主图和场景图规范。
- 明确一张图只呈现一个角度，禁止拼图。
- 加强交付前逐项自检；看不清的结构不得猜测或宣称完全准确。

## 文件说明
- `SKILL.md`：完整版规则，可用于支持 Skills 的环境或作为 Custom GPT Knowledge。
- `chatgpt-instructions.md`：精简执行指令，粘贴到 Custom GPT 的 Instructions。
- 本文件：使用说明。

## 使用方式
1. 提供真实产品照片；如果有活口、扣头、镶嵌等特殊结构，尽量同时上传对应近照。
2. 说明要做的图片类型，例如：“参考这些图，生成一张单独的平面拍摄图，重点保留戒指上下交错的活口结构。”
3. 如果是现有图片修复，说明要修复的具体位置，并指出其他部分保持不变。
4. 多张图片请逐张生成，不能拼成一张图。

## 建议图片类型
- 主图：纯白背景，完整展示产品。
- 细节图：一次突出一个结构或材质细节。
- 真人佩戴图：展示真实佩戴比例。
- 平面图：自然平放，清楚展示完整结构。
- 场景图：有氛围但不遮挡产品。

## 首次测试
先选一款有明显结构特点的首饰测试，建议检查：
- 宝石数量、颜色、镶嵌是否与实物一致；
- 活口两端的高低、交叉点和上下穿插关系是否正确；
- 平面图是否完整自然，没有悬浮或变形；
- 佩戴图的人体结构和首饰比例是否真实；
- 是否每张都是单独图片，没有拼图；
- 实际导出尺寸和格式是否符合需要。

## 重要提醒
图片生成模型可能无法完美还原复杂结构。若参考图看不清，应补充近照；若生成结果仍有偏差，不要将其当作准确的实物展示图。上架前请人工核对实物。TikTok Shop 的图片与 AI 内容政策可能更新，发布前请以 Seller Center 当前规则为准。本 Skill 不保证平台审核通过。
